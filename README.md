## Идея

**AATE** — это не проверка знаний, а проверка того, насколько хорошо вы понимаете друг друга.

Один игрок отвечает на каверзный вопрос про отношения. Второй пытается угадать его выбор. За совпадение — очко. Роли меняются каждый раунд.

> Вопросы не имеют "правильного" ответа. Важно не то, что выбрали вы — а то, совпали ли вы с другим человеком.

## Правила

### Подготовка
1. Откройте **экран хоста** на большом экране (ПК/планшет)
2. Два игрока заходят с телефонов по ссылке
3. Вводят ники и подключаются к комнате
4. Хост нажимает **Старт матча**

### Раунд

| Фаза | Что происходит |
|------|----------------|
| **Вопрос** | На экране хоста появляется вопрос и 3 варианта |
| **Ответ** | Активный игрок выбирает свой реальный ответ (скрытно) |
| **Угадай** | Второй игрок пытается предсказать выбор первого |
| **Раскрытие** | Оба ответа раскрываются на экране хоста |
| **Итог** | Если совпали — угадывающий получает +1 очко |

### Завершение
- Матч длится до конца колоды (15 вопросов)
- Победитель — игрок с большим количеством очков
- При равенстве — ничья

### Пауза
- Любой игрок может поставить игру на паузу
- Только тот, кто поставил — может снять
- Таймер фазы останавливается на время паузы

## Как начать игру

### Что нужно
- 3 устройства с браузером (1 ПК/планшет + 2 телефона)
- Все устройства в одной сети (или по интернету)

### Запуск

1. Откройте на ПК: `http://IP-СЕРВЕРА/` — **экран хоста**
2. На телефонах откройте: `http://IP-СЕРВЕРА/play` — **экран игрока**
3. На экране хоста отобразится **код комнаты** (4 символа)
4. Игроки вводят ники и код комнаты, нажимают **Войти**
5. Когда оба подключились — нажмите **Старт матча**

### Маршруты

| Путь | Назначение |
|------|------------|
| `/` или `/host` | Экран хоста (создание комнаты, управление матчем) |
| `/play` | Экран игрока (подключение, ответы) |

## Деплой

### Docker (рекомендуется)

```bash
# Клонировать репозиторий
git clone https://github.com/maamontov/aate.git
cd aate

# Собрать и запустить
docker compose up --build -d

# Проверить
curl http://127.0.0.1/health
```

Приложение будет доступно по `http://IP-СЕРВЕРА` (порт 80).

### Подключение домена

1. Настройте DNS A-запись: `ваш-домен.com` → IP сервера
2. Скопируйте nginx конфиг:
   ```bash
   sudo cp deploy/nginx/aate.conf.example /etc/nginx/conf.d/aate.conf
   sudo sed -i 's/aate.example.com/ваш-домен.com/g' /etc/nginx/conf.d/aate.conf
   ```
3. Выпустите SSL-сертификат:
   ```bash
   sudo certbot --nginx -d ваш-домен.com
   ```
4. Проверьте: `https://ваш-домен.com`

### Локальная разработка

```bash
# Терминал 1 — сервер
cd server
npm install
npm run dev

# Терминал 2 — клиент
cd client
npm install
npm run dev
```

Клиент: `http://localhost:5173`
Сервер: `http://localhost:3001`

## База вопросов

Вопросы хранятся в `questions/relations.ru.json`. Формат:

```json
{
  "id": "q_001",
  "text": "Как бы ты предпочел(а) провести идеальный вечер вместе?",
  "options": ["Тихо дома", "В новом месте", "Без плана, спонтанно"],
  "tags": ["relations", "lifestyle"]
}
```

**Требования:**
- Ровно 3 варианта ответа
- Нет "правильного" ответа
- Варианты должны быть близки по привлекательности
- Вопрос понятен за одно прочтение
